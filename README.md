# Fold Test

Six quiet puzzles played by reflecting flaps of tracing paper across straight creases. Match both the target footprint and the ink in every square. No score, time limit, sound, dependencies, network calls, account, or telemetry. Solved puzzles are stored in the current browser only.

The app is entirely static in `dist/`. Serve that directory from any static host. The fold rules, fixtures and hint search are separated from the UI. Run logic tests with `node --test tests/*.test.mjs`.

Artwork is geometric CSS and an original SVG paper icon.
